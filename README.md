# NULL-ALIBI — NUB Confidential SQL mystery demo (ELEC1)

Static prototype for the **NULL ALIBI** title-defense pitch
(CTELEC1L, Prof. Avila). No build step, no backend — double-click and demo.

## Run

- **Offline:** open `prototype-alibi.html` straight from disk.
- **Live:** https://null-alibi-kloudexa.vercel.app

- `prototype-alibi.html` — dossier, evidence wall, SQL console, accusation
- `engine.js` — real in-memory SQL evaluator (SELECT/WHERE/JOIN/ORDER BY/LIMIT)
- Destructive ops are contained + logged (cybersecurity-awareness mechanic)
- 3D evidence room: drag to orbit, click desks, unseal via missions
